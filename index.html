Projet Commande

Application Web dynamique connectée à une API Oracle ORDS

Accueil Clients Produit Colis Categorie

Bienvenue

Ce projet illustre la structure attendue dans le TP3. Il repose sur le schéma commande et consomme une API REST Oracle ORDS à partir du navigateur avec fetch().

Fonctionnalités incluses

  • Consultation des clients
  • Consultation des produit
  • Consultation des paniers avec détails
  • Ajout et suppression sur certaines pages

Avant de démarrer

  1. Créer la base Oracle avec le script SQL fourni
  2. Activer ORDS sur le schéma et les tables
  3. Vérifier les endpoints dans le navigateur
  4. Ouvrir le dossier dans VS Code
  5. Lancer avec Live Server
Important : l’URL de base ORDS se modifie dans js/api.js à la constante BASE_URL.

Pages du projet

  • clients.html : liste, ajout, suppression
  • produit.html : liste et recherche
  • paniers.html : liste des paniers et des items associés

Architecture

Frontend : HTML, CSS, JavaScript

API : Oracle ORDS

Base de données : schéma commande

Exécution : VS Code + Live Server
